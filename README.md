# Nandhana Vadakkan - Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Run in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Right-click and choose **Open with Live Server**.

No Node.js or Python is required.

## Main files
- `index.html` - portfolio content
- `assets/css/styles.css` - design and responsive layout
- `assets/js/main.js` - menu, typing animation, scroll effects and contact form
